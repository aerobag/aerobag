What is it?

Aerobag is a flight planning tool and electronic flight bag. It works the same online as a web app (for flight planning on the big screen) and as an Android app (for taking charts and plates with you offline).

Where did it come from?

I have been using Avare for almost as many years as it has existed. I love that it's open source. I love that I can have as many copies on as many devices as I want, so I have backups for my backups. (In fact, it was Garmin's device limit policy that drove me to cancel my Pilot subscription.) I love that it runs on Android so I don't have to use Apple's walled garden to take charts in the plane.

As awesome as all that is, I thought maybe it was time to take a stab at refreshing the concept. Aerobag a very direct descendent of Avare: you'll see its heritage everywhere. Here are some things that improve:

  • Same app web and tablet. The web (online) app fetches data on demand; don't try to use it on a poor hotspot. The tablet (offline) app lets you prefetch packages for the areas and types of flying you do.
  • Android Aerobag can manage multiple cycle packages simultaneously, so you can fetch the next cycle when the FAA publishes it (~20 days ahead) and already have it with you on your flight.
  • Offline regions depicted on map to help you plan packages
  • Efficient live weather feed protocol (if your hotspot works in the cockpit)
  • Rich vector layer with airports and airspaces
  • Click to inspect features on the map
  • Airways and approaches
  • Terrain warning layer
  • Better-organized plates and CSup pages
  • TACs paint over Sectionals so you don't have to switch between them
  • Warnings about stale data

Privacy

Aerobag doesn't have a privacy policy; you should assume we've been taken over by private equity and have already sold your middle initial.

That said, when you visit aerobag.org on the web, data is fetched on demand, which means the server traffic reveals what part of the world you're looking at. The Android client preloads packages, which reveals much coarser information, but its live-feed data stream may similarly reveal location information.

If you want to guard your privacy more closely, note that all of aerobag is open source. You can run your own server instance, which will fetch data from government sources.
