# Apps4Av Lineage

The initial chart cutline GeoJSON collection was adopted from the Apps4Av Avare
preprocessing tree. Aerobag now maintains a fork of that collection alongside
Aerobag-authored neatline corrections and legend layouts. The current files are
not a pristine copy of Apps4Av data, but retain their upstream provenance.

Aerobag's authoritative chart metadata lives in this directory. See `README.md`
for its structure and ownership.
